# TaskFlow — Adopted HolonStack Sample

`examples/taskflow/` is a synthetic, zero-PII three-package pnpm workspace (`@taskflow/core`, `@taskflow/api`, `@taskflow/cli`) showing a completed HolonStack adoption in action.

It omits `.agents/harness/` to avoid maintaining a third copy of the shared harness; `scripts/smoke-test.sh` stages `adopt-holon/.agents/harness/` alongside this folder and verifies `write check`, `check-docs`, and `isolate graph` on every run.
