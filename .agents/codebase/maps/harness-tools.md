## `harness/bin/` — bootstrap and generated shims

| File | Owns |
|---|---|
| `bootstrap.sh` | Checks Swift 6+ toolchain, runs `sync-settings.swift`, and runs generated `build.sh` to compile hooks and tools into `.cache/bin/` |
| `<tool-or-hook>` (generated) | Exec shims generated by `sync-settings.swift` that run `.cache/bin/<name>` (compiling on demand if missing) |

## `harness/tools/` — standalone Swift 6 CLI tools

| File | Owns |
|---|---|
| `write.swift` | Closure parser, template validator, 8-char hex ID minter (`.ids`), canonical writer, `done` criteria runner, and Markdown view renderer |
| `edit.swift` | Hash-checked exact-match and line-range atomic file editor with unified diff output and `--batch-file` support |
| `seek.swift` | Scope-aware declaration search and `--outline` returning `FILE:A-B` line ranges and file hashes for `edit --range` |
| `isolate.swift` | Build-manifest target graph loader (SwiftPM, Cargo, Node/pnpm, Go, CMake) and parallel worker claim manager |
| `check-docs.swift` | Verifies `AGENTS` banner, relative Markdown links, skill docs, and zero orphan docs against `AGENTS.md` and `ATLAS.md` |
| `lint.swift` | Swift 6 typecheck, `swift-format`, and `harness/lint.closure` rule checker for harness Swift files |
| `filter-run.swift` | Runs build/test commands, preserves full log in `.cache/`, prints filtered errors and summary lines |
| `perf-scan.swift` | Scans source loops for catalog smell spans |
| `perf-confirm.swift` | Runs verification checks on open performance findings |
| `perf-report.swift` | Renders `records/PERF.md` from `records/FINDINGS/` |
| `semantics-report.swift` | Scores semantics card routing efficacy and renders `records/SEMANTICS.md` |
| `transcript-md.swift` | Normalizes Claude Code and Gemini JSONL transcripts to compact Markdown |
