# inject-context

Archived transcripts live in `.agents/harness/.cache/compactions/claude/` and `.agents/harness/.cache/compactions/gemini/`. Each `<name>.jsonl` has a compact `<name>.md` sibling generated by `.agents/harness/bin/transcript-md` (turns, one-line tool summaries, files edited, files read, and failing commands).

1. **Read the record views first:**
   - `.agents/records/MEMORY.md`
   - `.agents/records/OPEN.md`
   - `.agents/records/TODO.md`
2. **Print the latest normalized transcript:**
   ```sh
   .agents/harness/bin/transcript-md --latest [any|claude|gemini] [--turns 10]
   ```
   - Pass `gemini` when picking up in Claude from a Gemini/Antigravity session, `claude` when picking up in Gemini from a Claude Code session, or `any` (the default) for whichever transcript is newest.
   - Pass `--turns N` (default `10`) to include more or fewer recent turns.
3. **Open the full `.md` when older turns matter:**
   The header of `transcript-md --latest` names the `Source` `.jsonl` path; its sibling `<source-stem>.md` in the same folder holds the whole session in Markdown.
4. **Trust stored records over transcript recaps:**
   When a transcript turn and a stored record under `.agents/records/` disagree, the stored record wins (`.agents/harness/rules/COMPACT.md`).
